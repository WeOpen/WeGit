The v1.1 and v1.2 features are combined in this public release candidate. / 本次公开候选版合并 v1.1 与 v1.2 的功能。

The same DMG contains native arm64 and x86_64 builds of WeGit and AskPass. macOS 27 is Apple Silicon only; this app back-deploys to macOS 26 for Intel. / 需要 macOS 26+、Apple Silicon 或能运行 macOS 26 的 Intel Mac，以及 Git 2.46+。同一个 DMG 中的主程序与 AskPass 都包含两种原生架构。

## Installation / 安装

1. Download the DMG and checksum to the same folder. / 将 DMG 和校验文件下载到同一目录。
2. Verify it: / 核对：

   ```bash
   shasum -a 256 -c WeGit-1.2.0-rc.1-macos-universal-adhoc.dmg.sha256
   ```

3. Open the DMG and drag **WeGit.app → Applications**, then launch WeGit from Applications. / 打开 DMG，将应用拖入 Applications，从应用程序目录启动。

This release is **ad-hoc signed and not notarized by Apple**. If macOS reports that WeGit is damaged, confirm the checksum and source, then run the following for this trusted application: / 本版使用 **ad-hoc 签名，未经 Apple 公证**。如提示已损坏，先核对来源和校验和，再为这份可信应用执行：

```bash
sudo xattr -dr com.apple.quarantine "/Applications/WeGit.app"
open "/Applications/WeGit.app"
```

The command removes WeGit's quarantine attribute. A checksum mismatch requires a fresh download. / 命令仅移除 WeGit 的下载隔离属性；校验和不一致应重新下载。

## Upgrade, data and rollback / 升级、数据与回退

Quit WeGit before replacing the installed app. The production bundle ID remains `com.willxue.wegit`; replacing the application does not delete repositories or saved application data. Back up repositories and drafts before downgrading to 1.0.0, whose feature set is smaller. Development builds use the separate `com.willxue.wegit.development` domain; their data is not automatically merged with production. / 替换应用前退出 WeGit。正式标识仍为 `com.willxue.wegit`，替换应用不会删除仓库或已保存数据。回退 1.0.0 前应备份仓库与草稿；开发域的数据不自动合入正式域。
