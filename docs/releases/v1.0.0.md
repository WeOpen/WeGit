# WeGit 1.0.0

First public release · 首次公开版本 · 2026-10-19

[Download / 下载](https://github.com/WeOpen/WeGit/releases/tag/v1.0.0) · [Website / 网站](https://weopen.github.io/WeGit/) · [Report an issue / 反馈](https://github.com/WeOpen/WeGit/issues)

## Requirements and signing / 要求与签名

macOS 27+, Apple Silicon / arm64, Git 2.46+. Version **1.0.0**, build **2**, bundle identifier **`com.willxue.wegit`**. MIT licensed. GitHub Releases and the website distribute the same ZIP.

**Ad-hoc signed; no Developer ID; not notarized by Apple.** Ad-hoc signing checks integrity but does not verify a developer identity. macOS may block first launch. There is no Mac App Store or TestFlight release.

要求 macOS 27 及以上、Apple 芯片和 Git 2.46 及以上。使用正式应用标识，采用 ad-hoc 完整性签名，**未经 Apple 公证，也没有 Developer ID 身份认证**。

## What is included / 功能

- Open and clone repositories; keep recent and favorite repositories.
- Read unified/split diffs, word changes and expandable context; page large disk snapshots and copy exact source text.
- Stage files or hunks, preserve commit drafts, amend commits and review branch history.
- Fetch, pull and push to explicit targets; choose a Pull strategy and recover supported merge/rebase conflicts. Check uncertain push results before retrying.
- Use English or Simplified Chinese without restarting, native menus and shortcuts, a menu bar panel, light/dark themes and a separate custom palette.

包括仓库管理、统一/分栏差异、大差异分页、文件/差异块暂存、提交草稿、分支与历史、明确目标的同步和冲突恢复，以及无需重启的中英文切换、原生菜单/快捷键、菜单栏面板和自定义主题。完整变更见 [CHANGELOG](../../CHANGELOG.md)。

## Install / 安装

1. Download `WeGit-1.0.0-macos-arm64-adhoc.zip` and its `.sha256` file from this release. Save both in the same directory.
2. In that directory, run `shasum -a 256 -c WeGit-1.0.0-macos-arm64-adhoc.zip.sha256`. Continue only if the result is `OK`.
3. Extract the ZIP and move `WeGit.app` to Applications. Make sure Git 2.46+ is installed, then open the app.
4. If macOS blocks an unverified developer, read [Apple's safe-opening guidance](https://support.apple.com/102445). Only if you independently trust this download, follow Apple's app-specific **Privacy & Security → Open Anyway** flow after attempting to open it. Stop on malware or damaged-app alerts and report the exact message.

下载 ZIP 与同名 `.sha256` 文件，在同一目录执行上述校验命令，确认 `OK` 后解压并将应用移至“应用程序”。首次启动可能受系统拦截；仅在自行确认来源可信后，按照 [Apple 官方说明](https://support.apple.com/zh-cn/102445)进行针对该应用的信任选择。无需关闭 SIP 或 Gatekeeper；不要移除整个目录的隔离属性。

Clean protected-Mac HTTPS installation and first-launch acceptance have **not been completed**. These instructions describe the intended installation path, not a claim that every system prompt has been validated.

## Existing preview data and rollback / 开发预览数据与回退

- Production and development builds use different preference domains. **1.0.0 does not automatically import development-domain settings or drafts.** Keep the preview app and its data if you need those drafts. Do not expect preview settings to appear automatically.
- Recent-repository data uses `~/Library/Application Support/WeGit/Repositories.store`, shared by the current development and production builds. Before switching, quit both apps and back up the **entire WeGit application-support directory**, including database sidecars. Back up important repositories separately. Opening a repository again does not require moving its Git data.
- This release changes the version/build and distribution documentation; it does not change the database schema. There is no earlier public stable version to upgrade from. Side-by-side preview/production data compatibility and rollback have not received clean-machine acceptance.
- To return to a preview, quit 1.0.0 and use your retained preview app. If restoring the shared database, quit both apps and restore the complete backup as one set. Keep the current data until you have confirmed your backup; do not delete repositories or preference domains as an installation step.

正式版不自动迁移开发域的偏好与草稿，请保留预览应用和原数据。最近仓库数据库目前共用上述目录；切换前退出两个应用，完整备份该目录（含数据库伴随文件），并另行备份重要仓库。本次没有数据库结构变更，但跨开发版/正式版切换与回退尚未完成独立安装验收。

## Validation and known limits / 验证与已知限制

The maintainer explicitly requested **“跳过辅助功能这块吧，直接上线发布 v1.0”** on 2026-10-19. This is a **one-time maintainer-authorized release exception for v1.0.0**. It supersedes the normal requirement to finish full acceptance before publishing this version. It does not turn incomplete checks into passes or change the default stable-release workflow.

- **Accessibility acceptance is deferred.** The latest SDK audit failed with 55 reports. Independent SDK controls reproduce some categories; VoiceOver, system display options and remaining practical readability checks are incomplete. See the [accessibility evidence](../ACCESSIBILITY.md).
- **Functional evidence:** hosted smoke 1/1, full native functional suite **45/45**, zero failures/skips, and reading matrix **144/144**, from [run 39137123756](https://github.com/WeOpen/WeGit/actions/runs/39137123756) at `2c2533c1f0ef7e084f57eae3144f616416e4d608`. This release changes version/build configuration, not application Swift code. This older run is not same-commit full acceptance. Nine Internal QoS runtime-warning nodes remain in its raw evidence. See the [scope and source inventory](../acceptance/2026-10-18/native-ui/final-functional/README.md).
- **Still unverified:** final-source complete performance sampling; protected-Mac HTTPS installation/first launch; real Beta feedback; GitLab/general hosting, interactive Pinentry/hardware keys and remaining credential-helper combinations. GitHub HTTPS/SSH transmission and isolated noninteractive OpenPGP checks have existing evidence; do not infer coverage of every environment.
- The existing hosted VM has SIP disabled in its original image. There is no dedicated protected acceptance runner. No security or accessibility settings are changed for this release.
- There is no integrated three-way merge editor or automatic updater. Keep a backup and review explicit Git operation targets.

辅助功能按维护者决定暂缓；最终源码完整性能、受保护 Mac 的实际 HTTPS 安装/首启、真实 Beta 和剩余兼容性范围继续列为未完成。**发布 v1.0.0 不代表这些验收通过。** 历史失败与后续跟进见[验收清单](../V1_RELEASE_CHECKLIST.md)及 [Issue #9](https://github.com/WeOpen/WeGit/issues/9)。
