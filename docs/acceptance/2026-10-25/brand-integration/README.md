2026-10-25，实施分支 `codex/v1-1-1-polish`，原检出与已有未提交1.1.1工作保留。新增变更以私有 `.build/brand-integration-before/` 的前置补丁和文件快照为基线。

## 本轮实现

- 接入R4 Icon Composer、浅深色兼容Dock图标、应用内Logo与字标、原生菜单栏分支轮廓；欢迎页与侧栏均使用新品牌，提交确认完成时使用同源「庫」印记。
- 浅色内容底 #F7F3ED、墨黑文字 #1F1F1F；深色反转为墨黑内容底与米白文字。印章红负责品牌/主要操作，危险操作仍有原生role、明确标题和独立结果符号，不靠颜色表达。
- 文件类型、状态、计数、导航、引用徽章与拉取/推送数量使用蓝、青、紫、橙、绿、玫红的语义分工；没有增加无意义状态圆点。保留原有17色自定义主题格式，已有主题不迁移、不覆盖。新的初始自定义主题为Ink & Ivory。
- 共享常规/小型/迷你/大型控件规则，主次动作使用相同label metrics；工具栏仍为36pt自有表面。Sheet显式安装同一风格与底色，修复“取消”与“创建”高度不同。提交为主动作，“提交并推送”保留同尺寸次动作样式。
- 保留主要布局、原生菜单所有权、键盘操作、已有结果反馈状态、草稿/会话身份和完整太极Loading；不改变Git读写流程。

## 性能与边界

材质只存在于品牌位图，不铺在代码或输入区，也没有新增连续纹理时钟。应用内Symbol降至256px、Icon至512px、字标至520px，保留完整母版；菜单与印章路径只解析一次。补充色沿用可读色缓存，不引入动画库。

这些是本地构建、独立AppKit检查和CUA渲染诊断，**不是XCTest通过或完整性能验收**。按现有工作流，本机未执行XCTest；最终托管回归、减少动效/对比度的完整原生状态矩阵以及既有性能门禁继续开放。没有合并、推送、发布或覆盖用户安装。
