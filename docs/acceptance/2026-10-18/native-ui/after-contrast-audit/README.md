## 19 条对比度报告的逐图复核

[W3C 对 1.4.3 的说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) 建议根据前景/背景声明值评估色对，并另行关注细笔画的实际可读性。本项目借用这一计算原则，不以截图极值或该说明自动宣布原生界面整体合规。用户确认保持色相和布局，当前没有依据这些像素再盲调全局色值或改动字体。
