# 仓库级 Remote 管理

从工具栏“更多操作 → 远端管理”进入。列表区选择远端，右侧分别显示获取与推送地址、关联分支和配置来源。没有独立 push URL 时，推送沿用获取地址。已有同步确认面板继续显示实际解析后的目标。

新增或编辑只写当前仓库的 `.git/config`。没有远端重命名、全局配置编辑或网络凭据管理。原有 fetch refspec、自定义远端键与未编辑配置保留。

简单编辑器支持单个获取地址和可选的单个独立推送地址。多地址、继承/include 来源和包含凭据的地址只读，保留 Terminal 入口。地址中的密码、查询参数与片段会脱敏；有凭据的现有值不会自动填入编辑框。SSH、HTTPS 和本地路径均作为参数处理，不拼 shell。

保存前后重验完整配置快照。地址变化后，旧的同步计划须重新确认。修改先写私有候选文件，持有仓库 `config.lock`，再用目录描述符锚定的原子替换提交；验证失败、取消或候选修改失败不提交半次 URL 更新，也不删除其他写入者的锁。

删除需确认远端与受影响分支。仅删除当前仓库拥有的远端配置及相关分支关联；本地远端跟踪引用、提交与工作区文件保留。继承的关联无法可靠在本仓库清除时不开放删除。要清理保留的引用，请在 Terminal 中明确处理。

读取配置文件上限为 4 MiB，Git 配置输出上限为 8 MiB。配置按键和精确 subsection 索引，避免远端数量增加时重复扫描全部配置。后台读取，编辑期间禁用重复写入，并在完成后刷新真实状态。[验收记录](acceptance/2026-10-23/remote-management/README.md)保留 30 次读取采样与未完成的应用级检查。
