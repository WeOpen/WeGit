# WeGit 辅助访问验收记录

更新：2026-10-11。**自动辅助访问审查尚未通过，VoiceOver 手动验收尚未完成。** 功能用例、窗口布局和辅助访问审查分别记录，不能用鼠标操作成功代替读屏与键盘验收。

## 1. 环境与范围

- macOS 27.0.1 / Xcode 27，Apple Silicon Mac16,8。
- Debug 原生测试，独立临时 Git 仓库、偏好与内存数据库。
- 浅色与深色模式，980 × 640 pt 内容区域；含系统工具栏的窗口为 980 × 692 pt。
- `LayoutTests/testAccessibilityAuditInBothThemes` 检查元素说明、动作、父子关系和对比度，保留每条报告及窗口截图。
- 当前审查涉及侧栏、历史列表、提交详情和提交文件差异；不能代替克隆、认证、设置和危险操作确认的完整辅助访问矩阵。

从项目根目录复现：

```bash
mkdir -p .build/accessibility
audit_run="$(mktemp -d .build/accessibility/audit-XXXXXX)"
xcodebuild -project WeGit.xcodeproj -scheme WeGit -configuration Debug \
  -destination 'platform=macOS,arch=arm64' -derivedDataPath .build-app \
  -only-testing:WeGitUITests/LayoutTests/testAccessibilityAuditInBothThemes \
  -resultBundlePath "$audit_run/Audit.xcresult" test
```

测试返回失败时，先看该结果包中的具体报告。结果包及原始截图保留在本机忽略目录中。

## 2. 已补齐的语义

- 历史搜索框说明搜索字段，提交图具有图像角色与分支列说明。
- 普通与磁盘差异的文件菜单具有“差异文件操作”名称。
- 差异块使用带块范围的分组说明，块内暂存与丢弃按钮仍独立可访问。
- 仓库切换器和分支切换器支持搜索、方向键和 Return；命令面板与仓库页面共用动作。

这些改进已经接入源码；只有实际通过的用例才计入对应验证结果。

针对本轮审查窗口的原始截图，以 AX 元素所在区域抽取主要前景和背景像素，并按 sRGB 相对亮度计算对比度。下表是局部实测，与部分自动报告存在差异：

| 文本 / 状态 | 前景 RGB | 背景 RGB | 对比度 |
| --- | --- | --- | ---: |

| 浅色普通代码 | 37, 38, 37 | 240, 249, 240 | 14.11:1 |
| 浅色新增标记 | 48, 98, 51 | 240, 249, 240 | 6.68:1 |
| 浅色侧栏 WeGit | 84, 86, 91 | 235, 235, 234 | 6.16:1 |
| 深色 SHA | 221, 221, 221 | 30, 30, 30 | 12.27:1 |

## 5. 关闭条件

- 核心流程具有实际可用的完整键盘路径和清晰的焦点顺序。
- VoiceOver 能正确朗读、进入及操作菜单、列表、差异与确认窗口；测试结束后恢复原状态。
- 自动报告逐项修复，或以实际辅助技术操作证据确认并记录明确的例外。
- 完成最小窗口、字号、密度及减少透明度/动态效果和增强对比度矩阵。

阶段进度见 [开发记录](DEVELOPMENT.md)，发布仍遵循 [PLAN](PLAN.md) 和 [发布门槛](RELEASE.md)。

## 6. 2026-10-11 手动尝试与恢复

隔离的 `ManualAccessibilitySession` 使用私有偏好、内存数据库和临时仓库，不打开真实用户工作区。系统“键盘导航”和 VoiceOver 原状态均为关闭，临时开启后已在系统设置中逐项恢复并确认关闭。VoiceOver 实用工具原有字幕面板为开启、欢迎信息为开启；未修改这两项。

键盘实测：⌘2 打开历史；Tab 定位“浏览范围”，Space 打开含“全部引用 / 当前分支”的菜单；继续 Tab 定位“搜索字段”，Space 打开“消息 / 作者 / SHA”。这确认两个报告控件的普通键盘路径，尚不足以关闭其 VoiceOver 动作报告。

VoiceOver 初次引导已退出，但本轮自动控制未取得可核对的朗读字幕，VO 激活命令也未产生可确认的菜单变化。因此不将其记录为 VoiceOver 通过，不增加统一忽略规则。手动夹具的 20 分钟等待达到上限后结束，结果包 `.build-app/v1-manual-accessibility-session.xcresult` 记录超时；这是验收会话未完成，不是产品功能测试通过。
