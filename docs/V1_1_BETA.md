# v1.1 Beta 交付与验收

更新：2026-10-23。本轮范围固定为 Stash、Remote、Tag、文件历史与定向搜索。准备 `1.1.0` / build `3` 的预发布制品；生成草稿和正式发布是独立步骤，未完成验收不会自动变为通过。

## 范围

四项功能均已实现并有托管原生专项。Cherry-pick/Revert 按原计划整体后移：当前识别外部序列状态，但应用内继续/中止仅支持 Merge/Rebase，缺少候选操作的冲突重开和不确定回执闭环。本版不增加其正式入口。

## 可执行的验证

- 必需 CI 保持仓库策略、Apple Git、最低 Git 2.46、Homebrew Git、真实临时 GPG 签名、应用/UI 编译和功能行为检查。
- `Native UI validation` 在可信 main 上先跑实际 1 项 smoke，再跑完整 functional 范围。保留总数、通过/失败/跳过数、xcresult、日志、截图与应用来源。
- `Native performance diagnostics` 只在 main 的一次性托管 VM 上执行。先通过实际 UI smoke，再运行普通/大型夹具的 30 次 Release 后台采样；原生性能先各执行 1 次，成功后才可选择 30 次界面、启动和滚动采样。
- 新功能后台夹具独立于普通/大型界面夹具，含 20 条 Stash、4 个 Remote、1000 个 Tag、5000 次修改同一文件的提交。每项 p95 预算 2000 ms；原始样本先写入报告，超预算保持失败。临时特性夹具在成功路径显式删除。
- 界面保留原预算：普通仓库外壳 500 ms、Status 300 ms、Diff 150 ms、History 300 ms、外部更新 1000 ms；1 次 smoke 的预算结论为 null。启动保留 30 次及 1000 ms p95 预算，滚动保留 30 次固定轨迹。RSS、Git 子进程峰值和 XCTest 内存指标分别记录。
- 测量结束后重建普通 Release，交付包不得残留 XCTest 测试签名权限。所有制品保留源码清单、版本、校验和及来源回执。

本机不执行 XCTest。已有独立后台测量和编译不替代上述托管原生采样。

## 发布边界

2026-10-23 查询仓库的自托管 runner 数量为 0。`Full acceptance` 所要求的真实交互 Mac 当前不可用；托管性能诊断不充当该门禁。现有稳定版发布仍要求同一 tag SHA 的成功 Full acceptance，不改 runner 标签或门禁脚本来绕过。

`Draft release` 对预发布 tag 使用既有 CI 门禁，并只创建草稿。Beta 草稿固定具体 SHA、包与校验和；干净目标 Mac 的下载/安装、迁移/回退、Beta 反馈与正式发布签字按实际结果记录。v1.0 的一次性发布例外不延续到 v1.1。

当前最终源码为 `c7f6fd2`；main CI 已通过。最终运行编号、实测结果和制品链接见[最终验证记录](acceptance/2026-10-23/v1-1-final/README.md)。完整功能仍在执行；30 次普通界面测量超预算，同环境基线对照与其余指标待补。Beta 草稿尚未生成。
