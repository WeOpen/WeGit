# v2.0 M0 契约与预算

范围由 [主计划](V2_0_PLAN.md)定义；本文冻结实现输入，不增加版本范围。[模块进度](V2_0_PROGRESS.md)分别记录实现、批次验收和交付。

## 基线与批次

固定 v1.2 基线 `127b553f9c35bb5bff7a1c66fa14eacced7d5798`，macOS 26+、Git 2.46+、无新增 Git 运行时依赖。R5、实时双语、草稿/未知写入回执继续保留。实机、受保护安装、完整 VoiceOver、整应用性能和 Beta 沿用原记录。

按流程组织 M0 工程、M1 控件/恢复、M2 建立/比较/文件/普通补丁、M2 主题/网站、M3 提交/任务/配置、M4 窗口/扩展仓库、M4 更新/分发和 M5 最终候选。模块可跨批次，子任务不会因此逐项重验。

草稿及 synchronize 的新 head 保持未验收；ready_for_review、直接打开稳定非草稿 PR，或重新添加 `batch:validate` 才安排实际范围检查。轻量策略保留，必需汇总拒绝延后/skipped 报绿。main 按真实输入核验，等价输入可引用已合入同仓库 PR 的证据。

## 快照与恢复

恢复记录 format 1 固定 UUID、工作区 realpath/gitDirectory/commonDirectory 身份、时间、操作/目标 OID、HEAD/索引摘要、原路径/类型/模式、备份字节摘要和成功/失败/未知回执。先原子保存并核对，再执行破坏性操作。未提交字节不依赖 Reflog；Reflog 只找回仍存在的对象。

文件与符号链接分别保存，拒绝沿符号链接父目录写入。外部变化使旧预览失效，特殊索引、Unborn/Detached、占用分支分别保护。序列固定起点/逐项 OID/mainline、完成/当前/剩余和 Git 状态；部分成功先核对，不整批重试。Git am 与其他 rebase-apply 分别识别。

硬Reset在首次status前固定全部已索引普通路径的文件版本（有界100000项），覆盖原干净文件的后来编辑；内容备份仍限1000文件/256MiB，未增加时间或空间预算。原提交与原索引树使用不同私有引用，以原子CAS事务保护/清理；拆分索引依赖单独保留并计入单项/总容量。所选恢复层核对其字节、对象和原模式，预览对象库为临时私有目录，不修改仓库对象；写入前的保护对象/引用及索引安装分别落盘。

默认保留最近20项、7天、总计1 GiB，单项≤256 MiB。未知/未核对失败记录不自动淘汰；超过预算在写入前停止，提供明确导出/清理。清理限定本应用私有目录中的固定备份身份。

## 窗口、主题与迁移

窗口 UUID 对应页面/阅读状态，工作区身份对应会话/草稿/写许可，common directory 对应引用/配置协调。会话按工作区复用，订阅计数，关闭一个窗口不取消其他窗口需要的操作。草稿共享且有编辑所有者/修订号，后开窗口不覆盖较新输入。

主题库 format 1 为稳定 entry UUID、v1 theme、activeThemeID；应用级共享。预览另有窗口所有者，取消只释放自己的预览。旧 customTheme 迁成第一项且保留旧原始数据；外部 JSON 仍只导出 version/name/controls/17 colors。迁移失败保留输入，不覆盖损坏数据。

`wegit://theme/import?v=1&data=<base64url-json>&sha256=<hex>` 只接收限定 host/path 和唯一白名单 query。负载≤8 KiB、整 URI≤16 KiB、文件≤64 KiB。摘要核对一致性；先预览，确认保存新 ID，启用另行选择。重复请求按内容摘要去重，名称不作覆盖身份。恢复未就绪时有界排队，最多8项，保留 Git 任务/草稿。

持久化 format 2 写入前备份原偏好/最近/收藏/各工作区草稿和页面。回退明确恢复原格式备份，不让旧版直接读新格式。写入/恢复固定命名空间和身份，测试使用隔离 UserDefaults suite。

## 发布、更新与三包

无新增第三方更新运行时，使用系统 CryptoKit Ed25519 验证独立来源签名，SHA-256 核对 DMG 字节。ad-hoc/macOS 信任独立记录。客户端不创建/存储生产签名私钥；发布端签名与公钥配置单独核对。无可信公钥或签名的现有 v1.2 制品不可自动安装。

更新清单 format 1 含版本/tag/channel/build/sourceCommit/minimumOS、发布时间/有效期、keyID、三种变体的 URL/SHA256/下载与安装字节/manifest、签名。签名覆盖规范 JSON 原字节；版本化公钥环限制生效范围。拒绝未知 key、过期、降级、通道错误、跨版本混包和任意来源。固定 GitHub Releases 与公开 HTTPS 清单，重定向/元数据有界，后台检查不进入 Status/Diff 路径。

文件名为 `WeGit-X.Y.Z[-rc.N]-macos-{universal|applesilicon|intel}-adhoc.dmg`。同 source/build 共享后端回执，分别核对全部 Mach-O/minos、资源、权限、签名、SHA 和只读挂载。安装者核对现有包、任务/窗口/持久化与空间后原子替换，失败恢复旧包；不通过操作用户现有安装或系统保护做测试。

网页先选语义版本/通道和完整版本，再选同版本架构。arm+64→arm64，x86+64→x86_64，未知/翻译环境→Universal；手动选择优先。不用 MacIntel/UA Intel、WebGL 或跑分判断 CPU。Release 刷新清单，保留最后有效快照/ETag，有界兜底；正常服务下5分钟可见，无访客直连 GitHub 或常驻轮询。

## 冻结的新预算

p95 至少30个有效串行普通 Release 样本，记录首次准备、缓存条件、设备和失败。本表是门槛，尚不是通过结论。原外壳/Status/Diff/History/事件/启动、后台2000 ms、取消500 ms与RSS256/512 MiB不变。

| 场景 | 规模/硬边界 | 验收预算 |
| --- | --- | --- |
| Reset/Reflog/恢复 | 普通100文件/16 MiB；大型1000文件/256 MiB；Reflog页100/总1000 | 首次预览/本地写入p95<2000 ms；取消<500 ms；备份遵守上限 |
| 比较/搜索 | 普通1万/大型10万提交、1万引用、10万路径；首批100，按需翻页 | 首批<2000 ms；后页<1000 ms；取消<500 ms；RSS≤256/512 MiB |
| 文件/补丁/多提交 | 普通16 MiB/100文件/10提交；大型32 MiB/1000文件/100提交；补丁≤32 MiB | 预览/单项写入<2000 ms；取消<500 ms；连续队列逐项记录 |
| 图片 | 单侧≤32 MiB/6400万像素；缩略边2048；双侧预计解码≤512 MiB | 缩略首批<2000 ms；切换取消<500 ms；RSS≤256/512 MiB |

## 输入证据与覆盖

Core/签名/行为/性能/应用/包分别计算 source/test/fixture/entry SHA，工具链变化同样失效。只接受 canonical workflow 的实际成功记录，并从源 Git 对象重算所有输入。缺失/过期/无法验证就实际执行。构建缓存不保存 XCTest/通过状态，包始终核对实际字节。

托管入口从可信 main 复制 ui_batches.json，一次 smoke 必须实际1/1、0失败/跳过，再一次 XCTest 执行完整注册集合并核对数量。基线集合仅代表 v1.2 回归，新增 V20 方法正常注册后才作为本版证据。最终冻结全部子任务/回归矩阵；实机/安装/VoiceOver等仍独立记录。
