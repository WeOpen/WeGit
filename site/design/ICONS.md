# 中国文化图标审查与扩展

2026-10-27：由 16 个扩充至 48 个。图标源是 `../public/assets/icons/culture.svg`，功能目录是 `../data/icons.json`，站点和工作台预览共用 `../src/scripts/icons.js` 的引用函数。

## 绘制约束

- 24×24 坐标系，主要轮廓保持 2 单位安全区；描边 1.65、圆端点及圆连接。
- 太极保留真实黑白两仪与鱼眼，外轮廓减为 1.3，避免实心主体显得过重。
- 功能含义优先：亭台对应返回首页，屏风对应主题，竹简对应文档，日晷对应历史，竹枝对应 Git 分支，签牌对应标签，锦囊对应 Stash，罗盘对应设置。
- 关闭、方向、选中等基础操作保留易识别的结构，避免为装饰增加无功能角标。没有字体图标、emoji 或位图缩放。
- 图标为装饰时隐藏于辅助功能树，操作名称放在真实按钮/链接上。

## 原有问题与处理

| 问题 | 修订 |
| --- | --- |
| 搜索镜内十字和过多细节 | 改为简洁探窗与圆柄，小尺寸仍可读 |
| 回纹刷新内有独立方框 | 去掉杂线，保留清楚的回转方向 |
| 关闭图标四角碎线 | 减为两笔合拢 |
| 下载图标像建筑，箭头不突出 | 收卷底托配明确向下箭头；导入采用配对向上版本 |
| 梅枝花朵过密、折扇骨架过多 | 减少重叠，统一圆角和笔画密度 |
| 多种导航借用同一个漆箱/卷轴 | 分别使用书函、日晷、竹枝、锦囊与签牌 |
| 不同图标的视觉粗细不一致 | 用同一描边和坐标网格重绘；太极作光学调整 |
