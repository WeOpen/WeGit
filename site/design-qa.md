# 404 页面还原与图标验收

日期：2026-10-27。范围：独立 404 页面、恢复操作、全站文化图标族。没有部署。

以下原型对照记录对应当时的独立导航版本。后续已按用户要求让 404 使用首页的共享导航和页脚，并完成紧凑主题按钮与资源缓存修订；旧截图的页头/页尾尺寸不代表当前实现。最新验收范围、结果与证据目录见 [HANDOFF.MD](../HANDOFF.MD) 的网站记录。

## Findings

最终同尺寸并排复核没有剩余可执行的 P0/P1/P2 问题。下表保留本轮发现及修订，生图的笔触变化与现有产品约束单独列出，不声称逐像素相同。

| 级别 | 发现与影响 | 修改与复核 |
| --- | --- | --- |
| P1，已修复 | 推荐标题消失、卡片顶部被裁：`overflow:hidden` 容器因程序滚动产生 80px 内部偏移 | `.error-bottom`、`.error-hero` 改为 `overflow:clip`；重载后内部 scrollTop 为 0，标题 y=898、卡片 y=961，见最终全图和 cards 局部 |
| P2，已修复 | 导航、按钮宽度和推荐标题字重偏离原型 | 导航按目标定位，主/次按钮 202/208px，标题采用 800 字重；相同 viewport 再截图比较 |
| P2，已修复 | 页尾高山抢占卡片区，品牌区背景过重 | 保留湖面与舟的基线，对上方山峰渐隐；见 cards 局部与全图 |
| P2，已修复 | 手机英文品牌短句换成多行，文字密度过高 | 单独减小英文短句字距，保持一行；最终 EN 手机截图中行高 14px，无横向溢出 |
| P2，已修复 | 1440px 宽屏插画放大后紧贴标题，印章压到右侧 4 上；768px 页面沿用桌面留白过长、四列卡片过窄 | 1123px 起按插画比例增加 hero 与正文偏移，印章跟随画面比例；681–1122px 连续缩短间距，860px 以下改为两列卡片；1440 与 768 最终截图复核 |
| P2，已修复 | WebKit 中 `type=search` 首次 Escape 只清空文字，需要第二次才退出 | 改用 `type=text`、`inputmode=search`、`role=searchbox`，并显式处理 Escape；IAB 输入“主题”后单次退出、焦点恢复已复验 |

| Image quality / asset fidelity | 主景保留 4–太极–4、双鹤、左亭台、群山、湖面与红叶；页尾保留两岸与小舟。4 张均由内置 imagegen 生成，PNG 原件保留，WebP 不插值放大；主景原生 1468/1469×1071，页尾 2172×724。品牌 Logo/「庫」印章使用 canonical 素材。实际 1:1 局部检查未见压缩糊块或透明白边。山峰、笔触、涟漪和舟的个体形状有生图变化，列为 P3，不作“完全相同”声明。图标按用户要求重绘为文化 SVG，未以 SVG/CSS 代替山水插画。 |

## 图标审查

原有 16 个逐一减少过密细节、统一描边，再增加 32 个，合计 48 个。亭台、屏风、竹简、罗盘、日晷、竹枝、锦囊等与功能语义对应；关闭、方向和选中保留清楚的通用结构。16/24/40px 浅深总览均实际查看，主页面引用与模板构建的符号 ID 一致。详见 [`design/ICONS.md`](design/ICONS.md)。

## 交互与技术验证

- 在 Codex IAB 实际点击返回首页、前往主题中心、重新加载；前两项到达对应中文页面，重新加载保留当前 404 路由。
- 搜索弹窗输入“主题”仅保留主题中心；一次 Escape 关闭并把焦点还给搜索按钮。弹窗有语义名称、输入标签与关闭按钮。
- Chrome 实际切换浅深色，确认 `picture.currentSrc` 分别为对应 hero/footer 资源；浅色干净重载只请求两张 light 画面。
- 768px 导航展开显示四个可点入口，无视口裁切；重新加载关闭导航。
- 显式 404 页面干净重载后的 Chrome console：0 error、0 warning。缺失文档的 HTTP 404 由本地服务器测试断言，不当作脚本报错。
- JS 测试 9/9，通过（其中发布行为文件包含 11 个子场景）；Python 构建/HTTP 测试 9/9，通过，覆盖三种 base path、中英文和 HEAD 语义。策略与 diff 检查通过。
- 站点构建约 2.47 MB，低于新增四张素材后的 3 MB 分发预算；单张主景 <450KB、单张页尾 <300KB。404 样式/恢复交互只在该页加载。无持续 Canvas/WebGL、无额外前端依赖。localhost 浅色资源 decodedBodySize 一次读取约 725KB，属于未压缩资源诊断，不是线上测速。
- 未部署，未执行原生 XCTest，也不将网站验证当作客户端或发布性能验收。

## 有意保留的产品差异与 P3

当前 R5 Logo、品牌「庫」印、太极外观切换及语言切换继承前一轮要求；这些与原型中旧标志和纯搜索导航存在差别。图标替换为中国文化元素是用户本轮明确要求。原型没有深色或手机稿，这些状态作为响应式扩展检查，不声称有同态视觉真值。

生图并非复制原始图层，笔画、地貌、仙鹤细节及舟形仍有细微差别。源图字体不可识别为唯一具体字库，跨系统回退的细微字形差异保留为 P3。没有剩余需要在交付前修复的 P0/P1/P2 项。
