# imagegen 提示集

工具：内置 image_gen；背景：真实透明。三个结果保存在 generated/。以下记录各次设计约束；几何母版的可复现输入是 source/render-brand.swift。

## 1. macOS 应用图标

Use case: logo-brand. Create a production macOS application icon for WeGit, a fast native desktop Git workbench. One straight-on square icon only. A clean off-white rounded square tile with restrained matte depth and transparent exterior. The central original geometric W is made from a thick cobalt-blue connected Git graph: rounded low bends, solid circular nodes at two outer upper terminals and the central junction, and a short vertical stem rising from that junction to a fourth node. The center is a real fork with three incident paths. Blue around #2B67D8. Precise edges, generous padding, recognizable at 32 and 16 pixels. No text, no terminal prompt, no code brackets, no orange Git diamond, no GitHub cat, no watermark, no external scene or mockup.

## 2. 图标外缘精修

Edit the generated icon while retaining the blue W graph, four nodes, topology, proportions, palette and white rounded tile. Change the exterior edge and finish only. Remove stray specks, rough edges and fringes. Smooth unbroken rounded square, centered with generous padding and genuine alpha outside. Restrained nearly flat off-white surface, no heavy bevel, no external cast shadow, no checkerboard, no text or additional elements.

## 3. 横版 Logo

Use the refined icon as identity reference. Create one production horizontal logo on genuine alpha transparency. Reproduce the same four-node W branching mark on the left, flattened to solid #2B67D8; remove the tile, texture, bevel and shadows. Set the exact word "WeGit" (W-e-G-i-t) on the right in a medium-weight contemporary humanist sans serif, dark ink #172033, carefully kerned and optically aligned. Comfortable space between mark and word. Only the blue mark and dark wordmark; no slogan, captions, grid, board or checkerboard.
