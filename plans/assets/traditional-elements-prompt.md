```text

WeGit 是一个原生 macOS Git 客户端，现有品牌为蓝色分叉 W，已经有完整太极图匀速旋转的 Loading。目标是克制、精致、现代的中国书房气质：纸墨承载记录，青瓷带来温润的控件材质，印章表达记录落定，册页和签条整理历史。保持现代系统字体、清楚的控件与大量留白。

1. 太极：松烟墨色与少量釉青的完整太极图，展示静态图形和轻微旋转意象。
2. 钤印：现有蓝色分叉 W 嵌入细方印构图，旁边给一个 18–20 pt 印章轮廓的「提交完成」控件片段，标注 pt 并说明输出像素按 2× 展示。功能成功使用一个清楚的成功符号，不在右侧重复放 W，不用红色表示成功。W 的正式形状以后用项目原矢量接入，不生成新的对称圆点 W。

4. 册页：线装书、细长签条，与「main」「v1.1.1」引用徽章形成呼应，保持现代易读文字。
5. 竹影：两三节疏竹与一段简洁山水留白，形成空状态插画；线条精细，没有浓重大片水墨。
```
