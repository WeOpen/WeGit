## 本轮视觉要求

- 必须按用户原图的主体关系和材质生成，不再以R2几何重绘的效果作为视觉标准。
- 奶白底座具有柔和厚度、暖边和接触阴影；朱砂面有真实印泥的微小颗粒、密度变化与墨孔，不用规则圆点代替。
- 印章模拟真实钤印：内部更饱满，缩小字与框之间的空白；近方形轮廓有自然圆转和微小起伏，边缘有轻微墨迹不均，不用完全笔直的CAD正方框。
- 印文依照前轮核实的小篆「庫」构形生成，保留「广」与「車」结构，不照抄参考图中未核验的印文。两枚印章保持同一风格。

## 文件性质

这是一轮**参考生图的位图资源**。整体视觉稿仍带有原参考的左下尾笔，独立Logo和Icon已要求移除尾笔；独立素材用于本轮资源审阅。生成式输出不等于共享SVG路径已经冻结，也不继承R2的157项几何检查。印文在生成图中的笔画与所有衍生版本仍需在正式矢量制版时统一复核。

已实际检查文件可解码、像素尺寸和透明通道，记录见 `ASSETS.json`；本轮未替换应用图标、编译Icon Composer工程或发布网站。

小篆构形辅助参考来自中央研究院小学堂崇羲篆體的U+5EAB；参考轮廓图与来源见上一级 `docs/SEAL-SOURCE.md`，字体出处 https://xiaoxue.iis.sinica.edu.tw/chongxi/ 。R3图形为生成式图像，不宣称与该字体原始轮廓逐点相同。
