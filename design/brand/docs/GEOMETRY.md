# R5 共享几何

完整独立生图原件保存在 `r5/generated/`。新参考板只供构图，不把板中的小图裁切交付。分支和字标从新 Logo 提取语义轮廓，区域信息保存在 `source/r5-master-regions.json`。随后 `refine-r5-geometry.swift` 对两个圆孔、主干曲线和底板边界作数学清理，输出 0.05pt 精度的统一轮廓，消除放大后出现的像素台阶。

默认 Icon 的分支和内印为白色，深色 Icon 两者均为 #1F1F1F。相同轮廓还生成 `BrandGeometry.swift`、菜单栏图标和功能符号。印文哈希固定在品牌规范和检查器中。不能用生图重绘的文字替代已核实的印面。

印泥来自独立生成的完整材质，经过基色校准到 #B3322D。纯几何 SVG 无字体、无位图；带材质 SVG 内嵌 JPEG。各输出在完整安全画布内渲染，不拉伸、截断或从参考板取小图。
