# 变更记录

## V1.0-R1 · 2026-10-25 · Codex

按 BRAND.md 生成朱砂红三节点、双位置小篆「庫」、衬线字标与奶白底座的统一矢量资源。新增浅深色横版、Icon Composer 工程、兼容 icns/iconset、单色功能符号、favicon 与 GitHub 物料。附源字形、OFL字体、几何参数与可复现导出脚本。

本稿缺少规范指代的原始右侧 App Icon 参考图，尚未进行真实应用与线上验收；保留 V1.0 方向，不升级为正式资产定稿。

## V1.0-R2 · 2026-10-25 · Codex

用户提供正式视觉参考，要求整体按图修改，并再次明确印章必须为小篆。核心改为斜主干、横分支的统一三节点；字标改为Libre Baskerville Bold；增加暖白底座层次、单色和深色图标变体。

重新查看CUHK小篆原图并核对中央研究院小学堂说明，印文改用崇羲篆體的U+5EAB原轮廓，不照抄参考图中未核验的印文。保留完整字体原件、许可、署名、核验说明与印章放大图。参考图已入库，R1的“参考缺失”限制解除；真实应用和GitHub页面验收仍未执行。

R1完整资源包仍保留在 `design/WeGit-brand-v1.0-r1.zip`，当前目录为R2。


## R3 · 2026-10-25 · 参考生图

用户否定R2的视觉还原，指出缺少质感、印面过疏及边框过于规整。使用内置image_gen直接引用原始参考图与小篆构形辅助图，生成整体视觉稿、透明横版Logo与透明App Icon，并做一次Icon外围透明抠图修整。文件和提示词在r3/。

此轮交付为PNG，未声称生成图共享冻结的SVG路径，也不继承R2的157项结构检查。R2旧稿及包保留追溯，当前入口切换到R3。


## R4 · 2026-10-25 · 按新Logo/Icon生成完整素材

从R3独立Logo提取分支、内部小篆印面和字标的闭合轮廓，冻结共享SVG。内外印章、Logo与Icon均共用相同路径，旧R2几何资源移至revisions/r2。使用内置image_gen从R3生成独立暖白/深色空底座及印泥材质，再由统一母版派生横版、Symbol、字标、方印、三套Icon、多尺寸、icns/iconset、Icon Composer、单色功能符号、头像、Banner、Social Preview及favicon。新增网页480/960 WebP和可复现重建脚本。

本地导出与实际ictool外观已检查；真实应用与线上页面接入不在本次制作范围。图形为纯矢量母版，材质组合SVG明确包含独立位图图层。
