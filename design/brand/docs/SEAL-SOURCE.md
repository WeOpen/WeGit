# 当前印章与来源

## R4：沿用R3紧凑小篆印面

用户明确要求：**印章一定用小篆「庫」**，并要求内部饱满、减少空白、近方边框有真实钤印的自然圆转与轻微起伏。

当前 `source/seal-ku.svg` 从新生成的R3 Logo内部白色小印提取轮廓，保留近方框、紧凑印文和自然边缘。它是当前内外印章的唯一母版。横版外印不再保留R3中与内印略有差异的另一份图形，而是将该母版等比放大、换为朱砂色。

当前印文继承R3生成图，其构形辅助参考是此前核实的小篆繁体「庫」U+5EAB，保留「广」与「車」关系。**R4轮廓同源检查不等于对生成字形做了新的文字学鉴定，也不宣称该路径与崇羲篆體原轮廓逐点相同。** 不应把“机器检查通过”当作字形出处证明。

## 构形核对来源

- [香港中文大学汉语多功能字库「庫」](https://humanum.arts.cuhk.edu.hk/Lexis/lexi-mf/search.php?word=%E5%BA%AB)：小篆图及《说文》记录，构形为「車」在「广」下。前轮实际查看了小篆原图。
- [中央研究院小学堂「崇羲篆體」制作说明](https://xiaoxue.iis.sinica.edu.tw/chongxi/)：说明见于《说文》的字依据大徐本形体书写。该字体U+5EAB用于前轮的构形辅助图。
- [崇羲篆體官方许可](https://xiaoxue.iis.sinica.edu.tw/chongxi/copyright.htm)：CC-BY-ND-3.0-TW-or-later；字体原件在前轮保留，未被修改。字形书写与制作背景的署名包括王心怡、谢清俊、庄德明、季旭昇，字体内版权标记为Academia Sinica 2022。

R3辅助图与提示词保存在 `r3/`；旧R2直接排印字体的说明存档在 `revisions/r2/docs/SEAL-SOURCE.md`。R4不依赖该字体文件，印面来源是R3独立Logo。正式字形审核应同时查看源图、当前SVG和上述参考，不能只看篆体字体名称。

`docs/seal-ku-proof.*`为前轮字体构形辅助图；当前R4印章请查看 `logo/seal-ku-red.svg` / `.png`，不要混用。
