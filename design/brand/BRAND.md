# WeGit 品牌视觉规范

版本 V1.0-R5 · 2026-10-25 · 1.1.1 应用接入版

本版按用户最新参考图重新制作，替代 R4 的三圆点分支和厚底座。以 `source/reference/r5-direction.png` 为构图参考；独立 imagegen 原图完整保存在 `r5/generated/`，交付图片不从参考板裁切。已经核实的小篆「庫」印文继续使用原始共享轮廓。

## 1. 品牌定位

WeGit 是原生 macOS Git 客户端。以 Git 分支为主体，以真实小篆印面作记号，表达简洁、可靠与专注。主体保持现代、清楚、克制；中国文化元素以印文和少量纸墨线描呈现。

## 2. 锁定的构成

- Git 图形只有**两个空心圆节点**：上方节点、右侧节点。斜向主干连至上方，水平支线连至右侧，左下方开放的主干延伸到底板边缘，没有第三个圆点。
- Logo 为红色 Symbol、粗衬线 WeGit 字标、字标右侧的小篆红印。Logo 没有奶白色应用图标底座。
- App Icon 为浅薄的米白或墨黑底座、红色主体、两节点分支与右下角小篆印文。
- **浅色 Icon：白色分支、白色「庫」印章及边框。深色 Icon：墨黑分支、墨黑「庫」印章及边框。**
- 图形、内印和外印共享路径。不得分别手调不同尺寸的节点或印文。

## 3. 颜色

| 名称 | 色值 | 用途 |
| --- | --- | --- |
| 印章红 | `#B3322D` | 红色印泥主体、Logo 外印、应用品牌强调 |
| 墨黑 | `#1F1F1F` | 浅色字标、深色底座、深色 Icon 分支及印文、深色应用基面 |
| 米白 | `#F7F3ED` | 浅色底座与应用基面、深色字标与正文 |

印泥质感围绕印章红作轻微明暗变化，不能把高饱和亮红当成基准色。生成材质原件与经过色值校准的工作材质分别保存；实际平均 RGB 在 `validation.json` 中记录。

应用的蓝、青、紫、琥珀、绿、玫红用于文件状态、数字、Badge、引用类型及操作语义。品牌三色构成大面积基面，语义色保留辨别信息。文字与按钮颜色通过原有对比度校准；导入自定义主题保持既有格式。

## 4. 分支母版

设计坐标为 566×566。R5 独立生成图作为几何依据，圆环与主干经过原生曲线清理，消除低分辨率锯齿。两个圆孔半径、笔画粗细和连接关系固定，底端保持开放。

`source/git-symbol.svg` 是纯矢量；`source/git-contours.json` 是封闭轮廓数据。应用的 `BrandGeometry.swift` 从相同数据生成，路径只解析一次。菜单栏功能符号省略印文，保持两个节点和完整主干，遵循系统模板图标着色。

## 5. 小篆「庫」印文

使用既有核实的小篆「庫」字形，不采用参考图中的疑似错字，也不由 imagegen 新字形覆盖。字形紧凑，内部留白有限，边框保留真实钤印的轻微不规则感。

纯印面坐标为 120×120，Symbol 内平移到 (382,420)。白印、红印和黑印仅改变颜色，不改变轮廓。`seal-contours.json` 的 SHA-256 必须保持：

`630e58e56e6835c59f03e252318f9b1ffb3a94f4b758598a0a1983b80ef76bf4`

文字学依据与来源继续见 [印文来源](docs/SEAL-SOURCE.md)。印章不能替代签名验证、发布状态或操作成功凭证。

## 6. Logo

横版基础画布 1200×400：Symbol 位于 (40,40)，宽 320；字标位于 (400,100)，按 0.6 缩放；外印位于 (1060,185)，按 0.72 缩放。保留完整透明边距，不能截去印章、字母或 Symbol。

字标使用固定轮廓，接收方无需安装字体。深色背景横版将 WeGit 字标改为米白；红色 Symbol 和红色外印保持一致。深色 **App Icon** 的黑分叉、黑印章规则独立应用于有墨黑底座的图标。

导出横版 SVG、1200／2400／4800 像素 PNG，另有 480／960 像素 WebP 页头资源。纯矢量字标可以独立使用；窄空间优先用完整 Symbol，不能挤压字距或非等比拉伸。

## 7. App Icon 与 Dock

- 兼容图标使用 1024×1024 画布；外底座主体宽高为约 824 像素，与本机 Finder、Terminal 同画布实测比例一致。
- 红色主体位于 (203,203)，宽 618，约为底座的 75%。
- 底边仅保留约 2 像素层次，近距离低透明投影。禁止厚重台座、长投影和夸张高光。
- Icon Composer 工程把分支、印文和印泥分成三个层。系统负责外层遮罩与光照，前景宽 768、位置 (128,128)，避免重复添加外部遮罩和底座阴影。
- Composer 的 Default 与 Dark 分别检查分支和印文的实际颜色；不能只检查工程 JSON。
- 兼容 ICNS 和运行中的 Dock 主题切换使用同一资源。主题切换不重启窗口，不重置工作区或草稿。

提供标准、深色、单色版，2048／1024 像素完整 PNG，以及 16／32／64／128／256／512 像素资源和原生 ICNS。

## 8. 质感与文件性质

印泥纹理由 imagegen 独立生成，保存在完整画布中，细微颗粒和浓淡变化不影响节点或文字识别。红色经过校准，不依赖生图结果对十六进制颜色的猜测。

分支、印文、字标和底座边界是可编辑矢量。带印泥的组合 SVG 内嵌 JPEG 材质；它是矢量前景与位图材质的组合，不宣称为全矢量纹理。2048 Icon 和 4800 Logo 从母版重新渲染，几何边缘不靠放大低清截图取得。

完整 imagegen 原图原生尺寸：Logo 为 2172×724，Icon 为 1254×1254；原图原样保存，不能把插值放大写成模型的原生分辨率。

## 9. 应用界面

大面积内容、工具栏及表单使用米白／墨黑；侧栏使用相邻的纸色和墨色层级。数字、Badge 和图标保留多种语义色。相同等级按钮共享高度与尺寸规则。

标签页采用同色基面，空态使用系绳签牌的细线插画。当前分支旁的领先数用紫色，落后数用青色；数据仍来自真实已核对的上游状态。

检查器随当前文件或提交变化。工作区显示文件路径、状态、增删统计、历史入口和差异块；提交、标签和储藏复用当前比较中的文件列表，选择文件驱动中央 Diff。展开检查器后精简 Diff 顶部的元数据；折叠后恢复中央入口。大型差异复用摘要或磁盘快照，不为侧栏额外读取整份文件。

## 11. 验收与复现

`source/rebuild.sh` 在本机从已保存原图、材质和共享轮廓重建资源，不再次联网生图。`scripts/sync-brand-resources.sh` 将资源同步到应用。

检查覆盖两个圆孔、相同路径、印文不变、完整透明边距、高清导出尺寸、材质基色，以及 Icon Composer 的浅深两版分支与印文颜色。原生检查另外比较 Finder 比例、应用内主题切换和上下文检查器，证据见项目 `docs/acceptance/2026-10-25/reference-inspector/`。

本地构建、独立行为检查和原生界面诊断不能替代托管 XCTest、完整性能与发布验收。旧规范保存在 `revisions/r4/BRAND.md`；旧结论不自动继承到新版本。
